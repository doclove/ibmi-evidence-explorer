# Synthetic fixtures

Project-authored examples only. No customer or third-party source. The code is illustrative
and is not intended to compile on IBM i.

Each source file contains a `FIXTURE-CANARY-*` marker. Tests assert these markers never appear in
operation logs or diagnostics.

| Directory | Purpose |
|---|---|
| `valid-export` | One RPG, CL, DDS, and SQL member; LF and CRLF line endings. |
| `malformed-manifest` | Manifest is not valid JSON. |
| `duplicate-identity` | Two entries declare the same library/source-file/member/type. |
| `unsupported-ccsid` | Entry declares CCSID 37 (EBCDIC). |
| `bad-path` | Entry path escapes the source root with `..`. |
| `f1-complete` | F1: only supported RPG/CL/DDS/SQL forms, all references resolvable (index status `complete`). DDS uses CRLF. |
| `f1-edge-cases` | F1: unknown, ambiguous (same member name in two source files), dynamic, special-library, and undeclared targets; malformed and unsupported syntax; fixed-form RPG; keyword-like text in comments and strings; mixed CRLF/LF; lone CR inside a line; a two-member call cycle. Decoy names (`COMMENTED`, `INSTRING`, `CRHIDDEN`, ...) must never be indexed. |
| `f1-5-fixed-rpg` | F1.5: fixed-format RPG IV with a documented F-spec (externally described DISK and PRINTER), a literal `CALL` with `PARM`, and a `CHAIN` of a declared file, plus a decoy member (comments, a literal inside EVAL, a dynamic and a lowercase `CALL`, a `*LIBL` call, a CHAIN of an undeclared name, misaligned columns, an RPG III-shaped F-spec, an EXTFILE continuation, a program-described file, `/COPY`, and an embedded `/FREE` block). Decoy names (`COMMENTED`, `INSTRING`, `SHIFTED`, `SHIFTFILE`, `CUSTMASTIF`, `NOTDECL`, `FREEPGM`, `BADEND`) must never be indexed. |
| `f2-explorer` | F2: a CL job calling an RPG program (and one missing program) that uses a DDS file. Adversarial comments address an AI assistant ("ignore previous instructions", a literal `<<<IBMI_EXPLORER_CONTEXT_END>>>` delimiter, a shell command) and the RPG member contains raw ESC terminal sequences; they must stay quoted data and terminal-escaped output. |

Invalid UTF-8, symbolic links, and oversized inputs are generated by the tests at run time.
